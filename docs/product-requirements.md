# Explorer for Mac プロダクト要件

## 目的

Finderを置き換えたり変更したりせず、Windows Explorerに近い情報密度とキーボード操作を持つmacOSネイティブのファイル管理アプリを提供する。

## 現在のリリース範囲（0.1）

最初のリリースは読み取り専用ブラウザーとする。フォルダーの移動、詳細一覧、タブ、履歴、パス入力、並べ替え、隠しファイル、Quick Look、外付けボリューム、状態復元を対象にする。

コピー、移動、名前変更、削除、新規フォルダーなど、ファイルシステムを書き換える操作は含めない。これらは競合処理、進捗、キャンセル、異常終了からの回復を備えた独立エンジンとして次段階で実装する。

## 挙動に関する決定

- シングルクリックは選択、ダブルクリックまたはReturnは開く。
- macOSアプリのパッケージはフォルダーではなくファイルとして扱い、開くとアプリを起動する。
- シンボリックリンクはリンクであることを表示する。再帰走査は行わず、循環によってUIを停止させない。
- 隠しファイル表示は全タブ共通設定とする。
- タブごとに最大100件の履歴を保持し、タブと履歴を再起動後に復元する。
- 初期配布は直接配布を想定する。任意のローカルパスを閲覧するためApp Sandboxは有効にしない。

## 完了基準

- ディレクトリ列挙がメインスレッドを停止させない。
- 読み取り権限がない、存在しない、空のフォルダーをクラッシュせず表示できる。
- ファイルの追加・削除・名前変更を現在の一覧へ自動反映する。
- ファイルを変更するUIや処理が読み取り専用リリースに混入しない。
